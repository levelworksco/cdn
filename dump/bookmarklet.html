Loads lw-ai-search.js and its dependencies straight off jsDelivr's GitHub CDN from the public levelworksco/lw-web-components repo (branch raj-web-component). jsDelivr caches branch URLs for a while, so a freshly pushed change may take a few minutes to show up — pin to a commit SHA instead of the branch name if you need the bookmarklet to track an exact revision.

Copy the code again after a change. The bookmarklet you saved is a frozen copy of the snippet below, and the snippet carries a dated cache-buster — without recopying it, your browser can keep serving a week-old build of lw-ai-search.js no matter what has been pushed.
